# Bike Workshop Management Module for Odoo

## Overview
The **Bike Workshop** module is a custom Odoo application designed to streamline and manage bike repair, maintenance, and rental workflows within a workshop environment. It provides a clean, user-friendly interface to track bikes through their lifecycle states.

## Main Features
* **Lifecycle State Tracking:** Easily manage bikes across five distinct states: `New`, `Available`, `Rented`, `Maintenance`, and `Cancelled`.
* **Pricing & Constraints:** Configure daily rental prices with built-in data integrity checks and unique naming validations.
* **Simplified UI/UX:** Clean, flat form views tailored for rapid data entry without cluttered notebook tabs, plus streamlined top-level menu navigation (`Bikes`).

## Installation & Setup
1. Clone or copy the `bike_workshop` module directory into your Odoo custom addons path (e.g., `addons/`).
2. Restart your Odoo server.
3. Activate **Developer Mode** in your Odoo instance.
4. Go to **Apps**, click on **Update Apps List**.
5. Search for `Bike Workshop` and click **Install**.
